# SainsLab

Aplikasi belajar sains interaktif berbasis Python dan Streamlit.

## Menjalankan di Windows

Pasang dependensi satu kali:

```powershell
python -m pip install -r requirements.txt
```

Setelah itu, klik dua kali `MULAI_SAINSLAB.bat`. Biarkan jendela terminal tetap terbuka saat menggunakan web app. Jika ditutup, server web berhenti.

Atau jalankan manual dari PowerShell:

```powershell
python -m streamlit run app.py
```

Streamlit akan menampilkan alamat lokal, biasanya `http://localhost:8501`.
